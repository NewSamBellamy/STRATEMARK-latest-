Deep Competitive Intelligence

Wispr Flow: Architectural Teardown & Pipeline

Wispr Flow achieves sub-700ms conversational voice-to-text by combining local Voice Activity Detection (Silero), WebSocket streaming STT (Whisper Turbo), and a fast "Middle AI" editorial pass.

The 4-Phase Underlying Pipeline

Sub-700ms End-to-End Pipeline

  • 1. Local VAD (Silero): Detects speech on-device (<15ms) via WASAPI/CoreAudio hotkey hook.
  • 2. Streaming STT: Streams audio chunks to cloud Whisper Large-v3-Turbo (~250ms).
  • 3. Middle AI Pass: Fast LLM (Gemini Flash Lite / Groq) strips filler words and fixes tone (~300ms).
  • 4. Active Focus Injection: Injects text via Accessibility API / clipboard restore without breaking focus.
# Working Middle AI Call curl -X POST "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-lite:generateContent?key=$API_KEY" \ -H "Content-Type: application/json" \ -d '{"contents":[{"parts":[{"text":"Clean filler words from: 'hey um so we need to test whisper turbo'"}]}]}'
